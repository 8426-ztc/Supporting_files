# Supporting_files
A reproducible research pipeline for clinical/medical AI analysis, including source data, LLM prompts, quality control, figure generation, and reporting.


## 📁 Directory Structure 

*   **`01_tables_and_source_data/`**: Raw data, source tables, and processed datasets. 
*   **`02_code_and_prompts/`**: Analysis scripts, modeling code, and LLM prompts. 
*   **`03_quality_control/`**: QC scripts, data validation, and checking logs. 
*   **`04_figure_files/`**: Generated figures, plots, and visualizations. 
*   **`05_reporting/`**: Manuscript drafts, supplementary materials, and reporting summaries. 
*   **`MANIFEST_SHA256.csv`**: Checksums for data integrity and reproducibility tracking. 

## 🚀 Reproducibility / 可复现性
All data and results can be traced via the SHA256 manifest.
